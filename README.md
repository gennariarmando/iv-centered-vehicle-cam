# IV Centered Vehicle Cam
This plugin removes the off center vehicle camera in GTA IV, and makes it similar to GTA V and 3D era GTA.\
\
For GTAIV The Complete Edition Only.

# Warning:
## This plugin has been merged into latest [FusionFix](https://github.com/ThirteenAG/GTAIV.EFLC.FusionFix), so technically if you only interested into removing the offset camera, just use fusion fix and ditch this.
